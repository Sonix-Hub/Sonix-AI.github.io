Getting Started
Create an Account / Log In
Safe
Creates an account so your chats and settings can sync across devices. Sign in with email (a 6-digit code is sent to verify it's really you — no password to remember) or with Google.
  1. Enter your email, or tap "Continue with Google"
  2. If using email, check your inbox for a 6-digit code and enter it to finish signing in
Continue as Guest
Caution
Lets you use SONIX without an account. The trade-off: guest chats live only in this browser's local storage and are not synced or backed up — clearing browser data or switching devices loses them.
Two-Factor Authentication (2FA)
Safe
Adds a second step after signing in, in Settings → System & Security → 2FA Verification. Pick one method:
  1. PIN Code — a 4-digit code you set and re-enter at login
  2. Pattern Lock — draw a connect-the-dots pattern (like Android's lock screen)
  3. Fingerprint / Face — uses your device's own biometric hardware (Face ID / Touch ID / Windows Hello) through the browser. This never leaves your device.
  4. Verification Code — a 6-digit code shown right on your screen at login, which you type back in. It's still a genuine second step, just delivered on-device instead of by email.
Chatting
Sending a Message
Type in the box at the bottom and hit send (or Enter). Whichever model is active in System Models will reply.
Attaching a File or Image
Safe
Tap the + button next to the input box, then "File." Images preview inline; other files show as a document card. Both get Save and Delete buttons — tap the ⋮ on the attachment to reveal them.
Voice Messages
Safe
Tap the microphone icon to start recording — a bar appears showing elapsed time.
  1. Tap the mic to start recording
  2. Tap Send in the recording bar to finish and send it, or Cancel to discard it
  3. Your voice is transcribed live, in-browser, so the AI understands what you said
  4. The message appears as a playable waveform bubble with Save/Delete options
NoteTranscription runs locally in your browser — nothing is uploaded to transcribe it.
Message Actions
Tap any message to reveal action buttons — they change based on what was sent:
  1. Text messages (yours): Copy, Edit, Delete
  2. Text messages (AI's): Copy, Retry, Search, Share, Delete
  3. Files, images, voice messages: Save, Delete
Code & the Live Map
Code Cards (Preview / Code)
Safe
When the AI sends code, it appears as a card instead of raw text, with:
  1. Preview — for HTML, CSS, JavaScript, and SVG, runs the code live in a sandboxed frame (only shown for languages with something visual to render)
  2. Code — the raw source, in a scrollable box (huge files load in chunks so they don't lag)
  3. Copy — copies the code to your clipboard
  4. Download — saves it as a real file on your device, with the correct extension
  5. Fullscreen (on previewable code) — opens the preview full-size, with its own Preview/Code switcher
Try asking"fizzbuzz in python" · "hello world in java" · draw an svg circle
Live Map
Safe
When the AI's reply mentions a place — or you explicitly ask for one — a small map bubble appears automatically, styled green-on-black. Uses free, keyless map data (OpenStreetMap), no account involved.
  1. Tap Fullscreen on a map bubble for the full interactive map
  2. Use the search bar inside to look up any place directly
  3. Toggle the coordinate Grid on/off
  4. The badge on each map (e.g. "City", "Country") shows exactly what kind of place was matched, so it's never ambiguous
Try asking"map of Tokyo" · "where is the Eiffel Tower located"
Sessions
Rename
Long-press (or tap ⋮) on a session in the sidebar, then "Rename" to give it a custom title instead of the auto-generated one.
Add to Favorites
Marks a session so you can find it quickly later, without deleting or archiving anything.
Save
A separate marker from Favorites — use it however suits you, e.g. "things to revisit."
Archive
Moves a session out of your main list without deleting it — useful for decluttering without losing history.
Export Chat
Safe
Downloads the whole conversation as a plain .txt file to your device — a personal copy you control, independent of whatever is synced or stored elsewhere.
Delete
Careful
Moves a session to a temporary "deleted" state. Confirm carefully — for signed-in accounts this also removes it from the synced database, not just this device.
Search Chat
Safe
Opens a slim search bar at the top of the conversation (it never covers the chat). Type a word to highlight every match, with a counter and up/down arrows to jump between them — similar to Ctrl+F.
Files & Links
Safe
A gallery of everything exchanged in a session, sorted into tabs: Images, Links, Files, Voice, Code. Tap anything to jump straight to that exact message in the conversation — no more scrolling through a long chat to find something.
System Models
SONIX Core
The original built-in model. Always available, can't be removed, and needs nothing set up.
Quick Free AI
Safe
A free built-in model with no login, signup, or key required. Good for short chats. Being a small free service, it can occasionally be slower or briefly unavailable.
Adding Your Own Model
Read First
In System Models → "Add Custom Model," paste an API link (required) and a key (only if that API needs one). This key stays local to your browser — it is never synced to our servers, even if you're signed in.
  1. The link is tested automatically in the background right after saving
  2. A green dot means connected and working; red means the last test failed, with the reason shown
  3. A "Network/CORS error" specifically means the browser blocked reading the response — this can happen even when the API genuinely works, because it usually means the server doesn't allow cross-site requests. That's a setting on the API's side, not something fixable from here.
Settings & Security
App Details
Safe
Explains exactly how SONIX stores your data (locally as a guest, synced to our database when signed in) and what that means practically — tap the "ℹ Where is my data stored?" button to expand it.
Export / Import All Data
Safe
Export All Data saves everything (sessions, settings, models) as one file you control. Import Data restores from that file — useful when switching devices or browsers, or as a personal backup on top of whatever is already synced.
Clear Current Chat / Clear All Data
Careful
Permanently erases what it says — the current conversation, or literally everything SONIX has stored for you. For signed-in accounts this also clears the synced copy in our database. There's no undo once confirmed.
Safety Notes
API Keys vs. Links — what's actually risky
Important
An API key works like a password: anyone who has it can use your account and run up your usage or charges. Never share it, and never paste one someone told you to keep secret. An API link alone is usually far less risky to share, since most links don't work without a key too — but avoid sharing a link that has a key baked directly into the URL.
Where Your Data Actually Lives
Safe
Guest mode: everything stays only in this browser's local storage — nothing is sent anywhere except requests you explicitly trigger (a custom model call, or a map/research lookup).

Signed-in accounts: your conversations and settings are also synced to our database (Cloudflare D1) so you can pick up where you left off on another device. Custom model API keys are the one exception — those always stay local to the browser that added them and are never synced.
Guest Mode: No Automatic Backup
Caution
As a guest, clearing your browser's site data, or switching devices/browsers, erases everything with no way to recover it — there's no synced copy for guest sessions. Signing in protects against this going forward, since your data syncs to our database. Use Export All Data or Export Chat periodically either way if you want a personal backup.
SONIX Core's Real Limits
Honest Note
SONIX Core is a pattern-matching engine, not a full language model — its code library covers about a dozen common exercises (FizzBuzz, sorting, etc.) across 10 languages. Ask for something outside that list and it will say so honestly rather than guess. For open-ended coding help, connect a real model under System Models instead.
SONIX — guest sessions run entirely in your browser and make no network requests on their own beyond what you trigger. Signed-in sessions sync to our Cloudflare-hosted backend as described above.
