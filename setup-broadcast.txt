SETUP: R2 BUCKET FOR MEDIA + ADMIN PASSWORD
=============================================

1. CREATE THE R2 BUCKET
------------------------
    wrangler r2 bucket create sonix-media

2. UPDATE wrangler.jsonc
-------------------------
Add an "r2_buckets" array. Your file should end up looking like this
(only the r2_buckets block is new — keep everything else you already have):

{
  "name": "sonixai",
  "main": "worker.js",
  "compatibility_date": "2026-01-01",
  "vars": {
    "ALLOWED_ORIGIN": "https://sonix-ai.pages.dev",
    "GOOGLE_CLIENT_ID": "646499820139-6o4cgp4179mbqns9fequ9ik9qnv3amo9.apps.googleusercontent.com"
  },
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "sonix-db",
      "database_id": "94c18b0a-08ba-4c35-b46b-27b742d2b630"
    }
  ],
  "r2_buckets": [
    {
      "binding": "MEDIA_BUCKET",
      "bucket_name": "sonix-media"
    }
  ]
}

3. SET THE ADMIN PASSWORD (as a secret — never a plain var)
--------------------------------------------------------------
    wrangler secret put ADMIN_PASSWORD

Pick something long and random — this is the ONLY thing standing between
the public internet and your broadcast/ban panel, since admin.html itself
has no other gate besides this password. Don't reuse a password from
anywhere else.

4. RUN THE MIGRATION
----------------------
    wrangler d1 execute sonix-db --file=./migration_broadcast.sql --remote

5. DEPLOY
----------
    wrangler deploy

6. UPLOAD admin.html
----------------------
Put admin.html in your Pages project same as the others (e.g. alongside
app.html and info.html), then redeploy Pages. Don't link to it from
anywhere in app.html or info.html — the only real protection here is the
password, so an unguessable/unlinked URL is a second (thin) layer on top,
not a substitute for a strong password.
